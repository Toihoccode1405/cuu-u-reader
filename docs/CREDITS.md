# Ghi công

## Icon cảnh giới
Các icon cảnh giới (whirlwind, stairs, concentration-orb, embryo, soul, magic-swirl, cauldron, moon, barbed-sun, eclipse, lotus, shatter, lightning-branches, portal, spark-spirit, galaxy, thunderball, nested-eclipses) lấy từ [game-icons.net](https://game-icons.net), theo giấy phép [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Tác giả của từng icon xem tại trang icon trên game-icons.net.

Dữ liệu được trích bằng `reader_frontend/scripts/gen-realm-icons.mjs` từ gói `@iconify-json/game-icons` (chỉ là công cụ lúc phát triển, không đóng gói vào ứng dụng).
